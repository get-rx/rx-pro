# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Pro, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Email security concerns to the maintainers privately
3. Include as much detail as possible:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide a detailed response
within 7 days indicating next steps.

## Security Best Practices

When using Pro:

- Always verify package checksums when possible
- Use `rx audit` regularly to check for known vulnerabilities
- Keep Pro updated to the latest version
- Review dependencies before adding them to your project
